# Woodworking Modeller

- Read `ARCHITECTURE.md` before adding or moving files. Follow its layers, folder rules and conventions, and use its Recipes for common changes (a new command, shortcut, interaction, saved field or overlay). If a change breaks a rule, either fix it or add it to "Known debt" there.
- Update `ARCHITECTURE.md` in the same change when the layout or a pattern changes, and `ROADMAP.md` when a feature lands.
- Before finishing any change: `npm run typecheck && npm test && npm run check`.
